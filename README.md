## 📸 Aperçu

> Atlas interactif présentant **250 huiles essentielles** avec leurs **noms latins**,
> **familles botaniques**, **compositions chimiques**, productions, prix et indicateurs
> économiques. Données réelles (FAOSTAT, UN Comtrade, OEC) et estimations sectorielles
> **clairement identifiées**.

| Vue | Description |
|---|---|
| 📊 **Vue d'ensemble** | Répartition par type, Top 15 par valeur, Top 12 familles botaniques, ratio réel/estimé |
| 🌿 **Catalogue** | 250 fiches filtrables (nom, latin, famille, molécule, source) |
| 📈 **Analyse détaillée** | Composition chimique + indicateurs économiques par huile |
| ⚖️ **Comparateur** | Jusqu'à 5 huiles comparées (radar + barres) |
| 📋 **Tableau** | Tableau complet triable sur 7 colonnes |

---

## ✨ Fonctionnalités

<table>
<tr>
<td width="50%">

### 🌿 Contenu botanique
- **250 huiles essentielles** référencées
- **Nom latin botanique** (genre + espèce + auteur)
- **Famille botanique** (Lamiaceae, Myrtaceae, Rutaceae…)
- **Composition chimique** (molécules principales + %)
- **~40 familles** botaniques distinctes
- **30 types** d'usage avec couleurs propres

</td>
<td width="50%">

### 📊 Données économiques
- **Production mondiale** (tonnes/an)
- **Prix de gros** (€/kg)
- **Valeur de marché** (M€)
- **Source identifiée** pour chaque huile
- Badge **✓ réel** (vert) ou **≈ estimé** (jaune)
- **15 huiles** avec données 100 % réelles

</td>
</tr>
<tr>
<td width="50%">

### 🎨 Interface
- Design **tricolore** vert
- **Thème clair / sombre** persistant
- **Responsive** (mobile → desktop)
- **Pagination** du catalogue (60 huiles/page)
- Accessibilité **WCAG AA**
- **Aucune dépendance npm**

</td>
<td width="50%">

### ⚙️ Interactions
- **Recherche instantanée** (nom, latin, famille, molécule)
- **Filtres** par type, famille, source
- **Tri** sur 5 critères
- **Comparateur** jusqu'à 5 huiles
- **Tableau triable** sur 7 colonnes
- **Fallback** si Chart.js indisponible

</td>
</tr>
</table>

## 🚀 Utilisation

### Option 1 — Cloner et lancer un serveur local

```bash
# 1. Cloner le dépôt
git clone https://github.com/gunout/dashboard-pharmacopee.git
cd dashboard-pharmacopee

# 2. Lancer un serveur HTTP (obligatoire pour fetch data.json)
python -m http.server 8000
# ou
npx serve

# 3. Ouvrir dans le navigateur
# http://localhost:8000
```
