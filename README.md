## 📸 Aperçu

> Dashboard interactif présentant **250 huiles essentielles** avec leurs données de production,
> prix, propriétés thérapeutiques, régions d'origine et indicateurs de durabilité sur la période
> **2000–2025**.

| Vue | Description |
|---|---|
| 📊 **Vue d'ensemble** | Doughnut par type, Top 15 valeur/prix, nuage de points prix vs production |
| 🌿 **Catalogue** | 250 fiches filtrables par type, triables, avec recherche instantanée |
| 📈 **Analyse détaillée** | 4 graphiques par huile : production/demande, prix, radar, durabilité |
| ⚖️ **Comparateur** | Jusqu'à 5 huiles comparées côte à côte (radar + barres) |
| 📋 **Tableau** | Tableau complet triable sur 7 colonnes avec filtres |

---

## ✨ Fonctionnalités

<table>
<tr>
<td width="50%">

### 🎨 Interface
- **250 huiles essentielles** référencées
- **30 types** distincts avec couleurs propres
- **Thème clair / sombre** persistant
- Design **responsive** (mobile → desktop)
- **Pagination** du catalogue (60 huiles par page)
- Accessibilité **WCAG AA**

</td>
<td width="50%">

### ⚙️ Interactions
- **Recherche instantanée** sur nom, type, régions, propriétés
- **Filtres** par type d'huile
- **Tri** sur 5 critères (nom, production, prix, valeur, rendement)
- **Tableau triable** sur 7 colonnes
- **Comparateur** multi-critères (max 5 huiles)
- **Export** et impression

</td>
</tr>
<tr>
<td width="50%">

### 📊 Visualisations
- Doughnut de répartition par type
- Top 15 par valeur de marché
- Top 15 par prix
- Nuage de points (bubble chart)
- Radar multi-critères
- Courbes temporelles 2000–2025
- Diagrammes de durabilité

</td>
<td width="50%">

### 🛡️ Robustesse
- **Aucun cookie**
- **Aucun traceur**
- **Aucune donnée transmise**
- Fallback si Chart.js indisponible
- Affichage des erreurs JS
- **Aucun serveur** requis
- Fonctionne en `file://`

</td>
</tr>
</table>

## 🚀 Utilisation

### Option 1 — Télécharger et ouvrir

```bash
# Cloner le dépôt
git clone https://github.com/gunout/dashboard-pharmacopee.git

# Ouvrir le fichier
cd dashboard-pharmacopee
open index.html      # macOS
xdg-open index.html  # Linux
start index.html     # Windows
```
